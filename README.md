# VeloGuard — Cycling Radar Landing Page (Sample)

A one-page English landing page for a fictional bicycle rear-radar and smart tail light.
Built as a portfolio sample to demonstrate Figma-to-code style landing page production with plain HTML, CSS, and JavaScript.

- **Demo:** https://ksolutionsjp.github.io/sample-lp-cycling/
- **Tech:** HTML / CSS / JavaScript (no frameworks, no external fonts or images — all visuals are inline SVG/CSS)
- **Sections:** Hero with radar sweep animation / Features (6 cards) / Interactive "How It Works" demo / Phone mockup app section / Specs / Pricing / FAQ accordion / CTA
- **Interactive demo:** A vehicle approaches from 140 m to 6 m (play/pause/replay plus a distance slider); alert states change in four stages and the time-to-reach is calculated live. The phone mockup in the app section syncs with the demo — its alert card, radar view, and tail light mode follow the same state.
- **Responsive:** Breakpoints at 1020px / 860px / 560px, with `prefers-reduced-motion` support.

Sample project — fictional product, created as a portfolio piece. Not a real store.
